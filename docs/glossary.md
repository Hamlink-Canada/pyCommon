# Shared Domain Terms

Shared credential records let trusted services agree on the current password for a node.

## Language

**Node credential**:
A node's current registration password together with whether it is enabled for use.

**Registration password**:
A system-generated shared secret used to prove a node's identity during registration.

**Entity**:
A shared organization identity that may be described as an organization, club,
or association. An Entity is not a Repeater Association.

**Entity owner**:
The Keycloak user who owns an Entity. An Entity with an owner is user-owned and
is not system-maintained.

**System-maintained Entity**:
An Entity with no user owner that is maintained by system administrators.

**Primary call sign**:
An Entity's main amateur-radio call sign. An Entity may have no call signs.

**AKA call sign**:
An additional call sign for an Entity that has a primary call sign.

**Entity Super Admin**:
A user assigned shared administrator authority for one Entity. Product-specific
administrator roles remain separate.
